What the kiosk does with it

Pack status
Under the selected person: whether the pack with their Bolero ID is on, its battery and antenna.
Flash
Selecting a person flashes their pack for ten seconds through its charger bay, when it is docked in a networked, licensed charger. Needs the admin password. A pack that is not in a charger is never flashed: before each flash RDR reads the antennas again, and says no if the pack is on air, its bay reads empty, it shows in two bays, or any antenna does not answer. The one exception is Test mode in the Flash tester below, for an admin checking that locate works.
Charger bay
With Riedel's Charger Monitoring licence on networked chargers the kiosk shows which charger and bay a docked pack is in. {% if bolero.ok %}{% if bolero.charger_resource %}Reading from /rest/{{ bolero.charger_resource }}: {{ bolero.chargers | length }} charger(s).{% else %}No charger data found on this system yet: look for it with the explorer below and enter the resource name.{% endif %}{% endif %}
Pack names
With Pack names on, the kiosk also finds people by the name set on their pack. Ask: the tech is asked when that name differs from the imported one, and chooses the Bolero name or the RDR name. Flag only: a name that differs is marked in search results and on the selected person, with no prompt, and nobody is renamed. Pack names hold 8 characters: the first 6 letters of the first name, a dot and the last name's initial, so Jonath.S matches Jonathan Smith and Kevin .W matches Kevin Wu, also with a space or nothing in place of the dot. Any other name cut short, or with an initial, counts as the same too. Default names like Bolero 61 are ignored.
Read only
RDR only reads, with the read-only account the Bolero web page uses. The one thing it ever sends is Identify, addressed to a charger bay. RDR refuses to send the antenna's own pack locate, which would flash a pack on someone's belt. It never changes names, keys, partylines or settings.
Network load
One request at a time. Pack status every 5 seconds while a kiosk is using it, every 30 seconds when nobody is, pack names once a minute. It backs off to one try every two minutes when the antenna does not answer.
No match
The kiosk says so when the person's ID is not on the system, or when they have no Bolero ID.

Test mode

The pack must be switched on: a pack in a charger is off and cannot answer a pack locate. Skips the charger checks, to see whether locate works on this system at all. The pack flashes and buzzes wherever it is, even on someone's belt. Only this page can do it. The kiosk and phones still never flash a pack that is out of a charger.
