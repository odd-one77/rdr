How matching works

People match on the unique ID when present, otherwise on name + phone. A matching name with a different phone (or vice versa) is flagged as a possible duplicate, and you choose: update the existing person, create a new one, or skip.

Devices match on SI number. Unknown device types from an easyjob export are created automatically. Status and current holder are never changed by an import.

Kit plans need a device type plus a way to find the person (unique ID, name or phone); quantity defaults to 1. A people sheet can also carry a "Kit" column such as Bolero, Pro-D2. Ambiguous names are flagged for you to pick.

Specific device pre-assignments work the same way but with the SI number, for the rare case where a particular unit must go to a particular person.
