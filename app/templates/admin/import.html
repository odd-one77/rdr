How matching works

People match on the unique ID when present, otherwise on name + phone. A matching name with a different phone (or vice versa) is flagged as a possible duplicate, and you choose: update the existing person, create a new one, or skip.

Devices match on SI number. Unknown device types from an easyjob export are created automatically. Status and current holder are never changed by an import.

Reserved devices need the device SI plus a way to find the person (unique ID, name or phone), for the rare case where a particular unit must go to a particular person. Ambiguous names are flagged for you to pick.

A person's Bolero ID comes in with the people sheet. When any Bolero pack is scanned out to them, the pack is shown under that ID until it comes back.
