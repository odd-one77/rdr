How matching works

Allocation rows match a person on the unique ID when present, otherwise on name + phone. A matching name with a different phone (or vice versa) is flagged as a possible duplicate, and you choose: update the existing person, create a new one, or skip. Rows without a name keep their position or role name as a placeholder, with the Bolero ID and faceplate colour; a name repeated with another ID becomes a second entry.

Devices match on SI number. From a delivery note PDF the description picks the type: BL-BPK → Bolero Beltpack, PRO-D1 / PRO-D2 / AIR-D1 / MAX-E1 / Covert → that headset, HC Headset Cord → Radio Headset Adapter, Hytera / Motorola → Radio, RSM → RSM. Panels, antennas, power, batteries, chargers, cables and cases are listed as ignored. Status and current holder are never changed by an import.

A person's Bolero ID comes in with the allocation. A pack labelled or reserved for them is linked to that ID, and any Bolero pack scanned out to them is shown under it until it comes back.
