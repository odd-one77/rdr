{% if not https_on %}

HTTPS is off. An admin can turn it on under Settings → HTTPS. Until then the phone view works over http for typing SI numbers, but the camera stays off.

{% else %}

Phone cameras only work on a secure address. Install the RDR certificate once per phone, then use {{ https_url }}.

Download certificate rdr-ca.crt

iPhone / iPad

  1. Download, then open Settings. Tap "Profile Downloaded" at the top and install it.
  2. Settings → General → About → Certificate Trust Settings: switch on "RDR Local CA".
  3. Open {{ https_url }} in Safari.

Android

  1. Download, then Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  2. Pick the downloaded rdr-ca.crt.
  3. Open {{ https_url }} in Chrome.

The certificate only vouches for this RDR server on this network. Valid for {{ cert.hosts | join(', ') }}{% if cert.expires %} until {{ cert.expires }}{% endif %}.
