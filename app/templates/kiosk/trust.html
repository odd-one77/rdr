{% else %}

Phone cameras only work on a secure address. Install the RDR certificate once on each phone, then use {{ https_url }}.

Download certificate rdr-ca.crt

iPhone and iPad

  1. Download, then open Settings. Tap "Profile Downloaded" at the top and install it.
  2. Go to Settings, General, About, Certificate Trust Settings and switch on "RDR Local CA".
  3. Open {{ https_url }} in Safari.

Android

  1. Download, then go to Settings, Security, Encryption and credentials, Install a certificate, CA certificate.
  2. Pick the downloaded rdr-ca.crt.
  3. Open {{ https_url }} in Chrome.

Cannot connect at all? On the RDR PC, allow python.exe through Windows Firewall for private networks, or open the HTTPS port.
